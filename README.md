# Mastering Software Testing — Student Materials

Everything you need to study with **Mastering Software Testing: Modern Practices
and Automation** by Mahmmoud A. Mahdi: the book, the printable worksheets, the
lab starters, and the runnable examples from each chapter.

The book is a draft edition released chapter by chapter. New chapters, labs,
and worksheets are added to this repository as they are published, so check
back or **Watch** the repository for updates.

## What is here

| Folder | File | What it is |
| --- | --- | --- |
| `pdf/` | `mastering-software-testing.pdf` | The book (reader edition) |
| `pdf/` | `student-worksheets.pdf` | Learning guides, graded worksheets, and practice sheets to print and complete |

## Requirements

- Python 3.9 or newer
- pytest 7 or newer (installed for you by the steps below)
- A terminal, and any code editor you like

Check your Python version with `python3 --version`. On Windows, use `python` or `py`.

## Using the worksheets

`pdf/student-worksheets.pdf` follows the book chapter by chapter:

1. **Learning guides** (ungraded). Read these first. They walk through one
   example from a requirement to an assertion.
2. **Chapter openers.** Fill in your details here. Each opener lists that
   chapter's sheets and has a grade record for your instructor.
3. **Graded worksheets.** Complete them in order, and write your name at the
   top of every sheet.
4. **Practice sheets** (ungraded). Extra practice for the same techniques.

Every row on the contents page links to its sheet. Print single- or
double-sided, A4.

When a worksheet asks for code and run evidence, attach your revised source
files and the console output from your test runs. Submit as your instructor
directs.

## Problems or mistakes?

If something does not run as described, or you find an error in the book or
worksheets, open an issue in this repository. Say which file and page, what
you expected, and what happened, and include your Python version and the full
error output.
